# Simon Game 🎮

This is a browser-based Simon Game built using HTML, CSS, and JavaScript.

## Features

* Random sequence generation
* User input tracking
* Level progression
* Sound effects on click
* Game over detection

## What I learned

* DOM manipulation
* Event listeners
* Arrays and sequence comparison
* Game logic design

## Note

This project was built as part of my learning process, with guidance and external help, and I fully understand the implementation.
